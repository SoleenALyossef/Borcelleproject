# Borcelle React — نسخة التعديلات

## تشغيل المشروع

1. افتحي مجلد المشروع في الطرفية.
2. نفّذي `npm install` لتثبيت الحزم المتوافقة مع نظام التشغيل لديك.
3. نفّذي `npm run dev` لبدء التشغيل المحلي.
4. افتحي عنوان التطوير الذي يظهر في الطرفية.

## التعديلات المضافة

- حماية صفحات الملف الشخصي والطلبات وإعادة الزائر غير المسجّل إلى تسجيل الدخول، مع الاحتفاظ بالمسار المطلوب للعودة إليه بعد تسجيل الدخول.
- تحسين التجاوب للشاشات الصغيرة والمتوسطة، بما فيها الجداول ولوحة الإدارة، دون تغيير لوحة الألوان الأساسية.
- جمع البحث والتصنيف ونطاق السعر والفرز في طلب المنتجات، مع تطبيق فلاتر العلامة التجارية والميزات والحالة والشحن محليًا على النتائج المطابقة من جميع صفحات واجهة البرمجة عند الحاجة.
- نموذج المنتج يدعم صورة أساسية إلزامية عند إنشاء منتج، وصورًا إضافية متعددة، ومعاينات للصور، وحقول الاسم والوصف بالعربية والإنجليزية.
- تحديث لوحة التحكم من بيانات واجهة البرمجة، وإعادة جلب الإحصائيات عند العودة إليها أو بعد تغييرات الإدارة، وعدم عرض عدد عملاء غير حقيقي في غياب واجهة مخصصة لذلك.
- دعم اتجاه الكتابة من اليمين إلى اليسار وخط Cairo عند اختيار العربية، وترجمة عناوين الواجهة بما فيها لوحة الإدارة، وإظهار أسماء المنتجات والتصنيفات وفق اللغة حين تتوفر حقول الترجمة من الخادم.

## ملاحظات على واجهة البرمجة

- يرسل نموذج المنتج الصورة الأساسية ضمن الحقل `image` والصور الإضافية ضمن الحقل `images[]` في طلب `multipart/form-data`، مع حقول الترجمة مثل `en[name]` و`ar[name]`. يجب أن يقبل الخادم هذه الحقول ويحفظ الملفات ويرجع مساراتها ضمن `image` و`images` كي تظهر في المتجر ومعرض الصور.
- معايير البحث والتصنيف والسعر والفرز تُرسل إلى واجهة المنتجات كمعاملات استعلام. الفلاتر التي لا يوفّر الخادم معاملات لها (العلامة التجارية والميزات والحالة والشحن المجاني) تُطبّق في الواجهة على النتائج التي جرى تحميلها.
- عدد العملاء يظهر بشرطة بدل رقم مضلل لأن إعدادات المشروع الحالية لا تحتوي على نقطة نهاية مخصصة لإحصاء العملاء.
